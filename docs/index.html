Smart Hiring, Fast Decisions

Letshire is a full-stack recruitment platform that digitizes the hiring pipeline from candidate registration and assessments to interview workflows and final decisions.

View on GitHub

The Hiring Challenge

Modern recruitment teams face speed, consistency, and visibility gaps that traditional tools don't solve.

Manual Screening Bottlenecks

Traditional resume review and early-stage filtering slow the hiring pipeline and make it harder to move quickly on strong candidates.

Inconsistent Evaluation

Candidate quality is hard to compare when assessments, interview feedback, and decision criteria vary across teams.

Limited Operational Visibility

Without shared dashboards and stage-level tracking, recruiters and interviewers struggle to see where candidates stand.

Poor Candidate Experience

Disconnected forms, manual follow-ups, and non-mobile flows create friction for candidates during registration and screening.

The Letshire Platform

Three independently deployable applications sharing one platform workflow.

HR Admin Dashboard

For: Super admins, admins, HR teams, and interviewers
  • Next.js dashboard for superadmin, admin, hr, and interviewer roles
  • Track candidates across assessment and interview stages
  • Manage organizations, roles, and registration links
  • Capture structured interview outcomes and feedback
  • Works as the internal control surface for the platform

Candidate Screening Portal

For: Job candidates (mobile-friendly)
  • Vite + React portal optimized for candidate-side flows
  • Token-based exam entry, onboarding, registration, and OTP verification
  • Job-specific MCQ, video screening, recording, and completion flows
  • Built-in anti-cheating protections for test integrity
  • Designed primarily for mobile and PWA usage

Backend Management System

For: Enterprise deployment and scaling
  • NestJS API serving both frontends from a shared backend
  • PostgreSQL-backed data model for candidates and hiring stages
  • AWS S3 and Bedrock integration for storage and AI features
  • Email notifications for key pipeline events
  • Role-based access and multi-tenant organization support

Frequently Asked Questions

What exactly is Letshire in this repository? +

It is an open-source monorepo containing three applications: a Next.js admin dashboard, a React candidate portal, and a NestJS backend API backed by PostgreSQL.

How do I run the platform locally? +

Install dependencies from the root with yarn install, copy each service .env.example, start PostgreSQL via docker compose up -d, and launch the apps with yarn dev.

What is the recommended contribution process? +

Fork or branch from main, keep changes focused, run linting and tests, use conventional commits, and open a pull request with a clear description of what changed.

How should security issues be reported? +

Do not open a public GitHub issue for vulnerabilities. Follow the repository security policy and report the issue privately or through a GitHub Security Advisory.

Which technologies are used across the platform? +

The current stack includes Next.js, React, NestJS, PostgreSQL, AWS S3, AWS Bedrock, Yarn workspaces, and Docker for local database setup.
