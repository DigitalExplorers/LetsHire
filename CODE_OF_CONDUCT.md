# Code of Conduct

This repository is committed to providing a professional, respectful, and inclusive environment for everyone participating in the project.

This Code of Conduct applies across the entire monorepo, including the HR Admin Dashboard, HR API, Candidate Portal, issue trackers, pull requests, discussions, and any other project communication channels.

## Our Standards

Examples of behavior that contribute to a positive environment include:

- Being respectful in language, tone, and technical disagreement
- Giving and accepting constructive feedback in good faith
- Focusing discussions on the work, not the person
- Being considerate of different backgrounds, experience levels, and perspectives
- Taking responsibility for mistakes and correcting them promptly

Examples of unacceptable behavior include:

- Harassment, intimidation, threats, or personal attacks
- Discriminatory, hateful, or exclusionary language or conduct
- Trolling, deliberate provocation, or sustained disruption of discussions
- Sharing private, confidential, or identifying information without permission
- Sexualized language, imagery, or unwelcome advances
- Any other conduct that would be inappropriate in a professional working environment

## Scope

This Code of Conduct applies in all project spaces and whenever an individual is representing this project or its community. This includes, but is not limited to:

- GitHub issues, pull requests, and discussions
- Code reviews and design discussions
- Project documentation and comments
- Community chats, demos, and other public-facing interactions related to the project

## Reporting

If you experience or witness behavior that violates this Code of Conduct, report it to the project maintainers through a private repository contact channel when available.

- Do not use public issues for sensitive conduct reports
- Include relevant context, links, screenshots, or timestamps when possible
- Reports will be reviewed promptly and handled as confidentially as reasonably possible

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct. They may take any action they deem appropriate in response to unacceptable behavior, including:

- Requesting a change in behavior
- Removing comments, commits, issues, or other contributions
- Temporarily restricting participation
- Permanently banning an individual from project spaces

Enforcement decisions will be based on the severity, frequency, and impact of the behavior, with the goal of protecting the community and maintaining a productive working environment.
